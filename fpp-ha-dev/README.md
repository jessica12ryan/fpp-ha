# FPP - Falcon Player App for Home Assistant (Dev)

[![FPP logo](https://raw.githubusercontent.com/jessica12ryan/fpp-ha/master/fpp-ha/logo.png)](https://github.com/FalconChristmas/fpp/)

> **Dev variant of `fpp-ha`** — not prebuilt, always compiles the `master` branch of [FalconChristmas/fpp](https://github.com/FalconChristmas/fpp) locally. Rebuild the add-on to pick up the latest `master`.

## Installation

- Install **FPP - Falcon Player (Dev)** (`fpp-ha-dev`) alongside or instead of the stable `fpp-ha`.
- Initial install builds from source, so it takes longer than the prebuilt stable add-on.
- You can open FPP by browsing to http://HA_IP or clicking the Open Web UI button.
- To update to the newest `master`, trigger a rebuild/reinstall of the add-on.
