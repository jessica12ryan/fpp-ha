# Security Policy

## Supported Versions

Only the latest version of FPP-HA is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v10.0   | ✅ Yes (stable)   |
| master  | ✅ Yes (dev)      |
| 1.0.0   | ✅ Yes (stats)    |

## Reporting a Vulnerability

If you discover a security issue in this repo, please open a private issue or
contact the maintainer via the GitHub repository at
https://github.com/jessica12ryan/fpp-haCommands/security/advisories

Please do **not** report security issues through the public issue tracker if they
could be exploited before a fix is released.

## Scope

This security policy covers the FPP-HA Home Assistant add-on repository only. Vulnerabilities in upstream Falcon Player (FPP) should be reported to the [FalconChristmas/fpp](https://github.com/FalconChristmas/fpp) project.
